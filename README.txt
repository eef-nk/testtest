================================================================
  PBS Editor  —  Pokémon Essentials v21.1+ PBS 파일 편집기
================================================================

■ 실행 방법

  [방법 1] start.bat 더블클릭  (권장)
    - Python 3 또는 Node.js가 설치된 경우 자동으로 로컬 서버를
      켜고 Chrome에서 앱을 엽니다.
    - 앱이 열리면 [📂 폴더 선택]으로 프로젝트 폴더를 직접 선택해
      주세요. (자동 로드되지 않습니다)
    - Python 설치: https://www.python.org/downloads/
      (설치 시 "Add Python to PATH" 옵션을 반드시 체크하세요)

  [방법 2] index.html을 Chrome 또는 Edge로 열기
    - Python/Node.js 없이도 사용 가능합니다.
    - 브라우저에서 index.html을 열고, 상단의 [폴더 선택] 버튼으로
      Pokémon Essentials 프로젝트 폴더를 직접 지정하세요.

  ※ Firefox, Safari는 파일 직접 저장 기능을 지원하지 않습니다.

----------------------------------------------------------------

■ 기본 사용법

  1. [📂 폴더 선택] → PE 프로젝트 최상위 폴더 선택
  2. 상단 탭 카테고리(포켓몬 / 기술 / 서식 분포 / 트레이너) 클릭
     → 드롭다운에서 편집할 파일 선택
  3. 왼쪽 목록에서 항목 클릭 → 오른쪽 편집 패널에서 수정
  4. Ctrl+Shift+S 로 저장 (또는 [저장] 버튼 클릭)

----------------------------------------------------------------

■ 저장 방식

  - Chrome / Edge (File System Access API 지원):
    PBS 파일에 직접 덮어씁니다.
  - 그 외 환경 / 미지원 시:
    메모리에만 저장됩니다. 탭 상단 [💾 파일 내보내기] 버튼으로
    파일을 다운로드하여 수동으로 교체하세요.

----------------------------------------------------------------

■ 지원 탭 및 특수 필드

  ▸ 포켓몬 / Gen9 포켓몬 / 폼 계열
    - GenderRatio   : ♂:♀ 비율 드롭다운 (예: 50:50 / 불명)
    - GrowthRate    : 성장 속도 드롭다운 (Erratic / Fast / Medium /
                      Parabolic / Slow / Fluctuating)
    - Types         : 타입 드롭다운 (단일/복합)
    - BaseStats     : HP·공격·방어·특공·특방·스피드 개별 입력
    - Abilities     : 특성 검색 드롭다운 (최대 2개)
    - HiddenAbility : 숨겨진 특성 드롭다운
    - Moves         : 레벨업 기술 (레벨 + 기술 검색)
                      ※ 저장 시 레벨 오름차순으로 자동 정렬
    - EggMoves      : 유전 기술 (기술 검색 드롭다운)
    - TutorMoves    : 가르치기 기술 (기술 검색 드롭다운)
    - WildItem*     : 야생 지참 아이템 드롭다운
    ※ 목록에서 Generation 필드(1~9)가 있는 포켓몬은 세대별 색상으로 표시됩니다.

  ▸ 기술 계열 (moves / Gen9 / 테라스탈 / 다이맥스 / Z기술)
    - Type          : 타입 드롭다운
    - Category      : Physical / Special / Status
    - TotalPP       : 5 / 10 / 15 / 20 / 25 / 30 / 35 / 40
    - Target        : 18종 타겟 드롭다운 (한국어 설명 포함)
    - Priority      : -7 ~ +7 드롭다운 (기본 = 0)
    - Flags         : 체크박스 목록 (표준 플래그) + 커스텀 입력란
                      (목록에 없는 플래그는 쉼표로 구분해 직접 입력)
    - Description   : 여러 줄 텍스트 입력
    ※ 항목 선택 시 위 필드가 항상 모두 표시됩니다.

  ▸ 서식 분포 (encounters)
    - 맵 이름, 서식 타입별 슬롯(확률·종족·레벨 범위) 편집
    - 서식 타입 추가 / 슬롯 추가·삭제 가능

  ▸ 트레이너 타입
    고정 필드: Name / Gender / BaseMoney / SkillLevel /
               Flags / IntroBGM / BattleBGM / VictoryBGM

  ▸ 트레이너
    헤더 필드: Items / LoseText
    포켓몬별: 종족·레벨·기술(최대 4개)·특성 인덱스·지참 아이템·
              성격·성별·닉네임·행복도·볼·이로치·쉐도우·IV/EV

----------------------------------------------------------------

■ 새 항목 추가

  포켓몬 / 기술 / 서식 분포 / 트레이너 타입 / 트레이너 탭에서
  목록 상단의 [+ 새 항목] 버튼을 클릭합니다.
  내부 ID 등 기본 정보를 입력하면 목록 맨 아래에 추가됩니다.

----------------------------------------------------------------

■ 항목 삭제

  편집 패널 우측 상단 [🗑 삭제] 버튼 — 더블액션 필요:
    1차 클릭 → 버튼이 빨간 점멸로 전환 (경고 상태)
    3초 이내 재클릭 → 삭제 확정
  ※ 3초가 지나면 자동으로 취소됩니다.

■ 변경 로그

  - 편집 내역은 브라우저 로컬 저장소에 자동 보존됩니다.
  - 앱을 재시작해도 이전 세션의 변경 내역이 유지됩니다.
  - [📋 로그] 버튼 → 변경 이력 확인 및 텍스트 파일로 내보내기
  - [로그 초기화] 버튼으로 전체 삭제 (로컬 저장소에서도 삭제)

■ 번역 불러오기

  [🌐 번역 폴더] 버튼 → Text_korean_core 또는 Text_korean_game
  폴더를 선택하면 포켓몬·기술·특성·아이템 이름이 한국어로
  병기 표시됩니다. (예: 이상해씨(Bulbasaur))

----------------------------------------------------------------

■ 커스텀 파일 자동 인식

  PBS 폴더에 _Custom.txt로 끝나는 파일을 추가하면,
  폴더를 열 때 자동으로 해당 탭이 생성됩니다.

  예시:
    PBS/moves_Custom.txt      → 기술 카테고리에 "기술 커스텀" 탭 생성
    PBS/pokemon_Custom.txt    → 포켓몬 카테고리에 "포켓몬 커스텀" 탭 생성
    PBS/encounters_Custom.txt → 서식 분포 카테고리에 "서식 분포 커스텀" 탭 생성

  새 항목 추가와 직접 저장 모두 지원됩니다.
  파일을 추가한 뒤 폴더를 다시 선택하면 탭이 나타납니다.

         - 변경 로그 영속화

  v1.1   저장 단축키 변경: Ctrl+S → Ctrl+Shift+S
         레벨업 기술(Moves) 저장 시 레벨 오름차순 자동 정렬
         미저장 변경사항 있을 때 저장 버튼이 두 색을 번갈아 점멸

         포켓몬 비교 패널 추가
           - BaseStats(기본 능력치), 레벨업 기술, 유전기, 가르치기 비교
           - 현재/비교 대상 간 차이 수치 표시 및 좌측 패널 필드 강조
           - 번역 로드 시 비교 대상 이름이 한국어로 표시
         진화(Evolutions) 필드 편집 지원
         콤보박스 클릭 시 텍스트 자동 초기화 → 즉시 검색 입력 가능
         [버그] 비교 패널이 버튼을 누르지 않아도 빈 칸으로 표시되던 문제 수정

  v1.3   트레이너 탭에서 엔트리의 특성명 병기
           - 특성 인덱스(0/1/2) 옆에 실제 특성 이름 표시
           - 종족 변경 시 특성 드롭다운 즉시 갱신
         트레이너 IV/EV "직접 지정" 토글 추가
           - 체크했을 때만 개체값(IV)·노력치(EV)를 PBS에 기록
           - 미체크 시 해당 줄을 저장하지 않음
         트레이너 파티에 폼 포켓몬 지정 가능
           - 종족 선택 목록에 폼 포켓몬 포함 (종족명-폼명 형태로 표시)
           - SPECIES,FORM,LEVEL 형식의 파티 항목 파싱 지원
         서식 분포 새 맵 추가 시 기존 맵에서 서식지 복제 가능
