    🚀 처음 시작하기

    PBS Editor는 Pokemon Essentials(PE) 게임의 데이터 파일을 코드 편집기 없이 쉽게 수정할 수 있는 도구입니다.
    PBS 파일이란 PBS/pokemon.txt, PBS/moves.txt 같은 텍스트 파일로, 게임의 포켓몬·기술·트레이너 등의 정보가 담겨 있습니다.

    ▶ 3단계로 시작하기

    1. 📂 폴더 선택 버튼 클릭
      Pokemon Essentials 프로젝트의 최상위 폴더(Game.exe 또는 Game.rgss3a가 있는 폴더)를 선택하세요. 앱이 선택한 폴더 안의 PBS 파일을 찾아 불러옵니다.
    2. 탭 버튼 클릭 → 편집할 파일 선택
      상단의 포켓몬 · 기술 · 서식 분포 · 트레이너 버튼을 누르면 드롭다운 메뉴가 나타납니다. 원하는 파일을 선택하세요.
    3. 왼쪽 목록에서 항목 클릭 → 오른쪽에서 편집 → Ctrl+Shift+S 저장
      Chrome 또는 Edge에서 실행하면 파일에 직접 저장됩니다. 그 외 브라우저는 파일을 다운로드합니다.
    💡 추천 브라우저: Chrome 또는 Microsoft Edge
    이 두 브라우저에서만 파일을 직접 저장할 수 있습니다. Firefox나 Safari는 지원하지 않습니다.

    🖥️ 화면 구성

    영역위치설명
    헤더최상단폴더 선택, 번역 불러오기, 탭 전환, 로그, 내보내기 버튼이 모여 있습니다.
    목록 패널왼쪽현재 선택한 탭의 항목(포켓몬·기술 등)이 나열됩니다. 클릭하면 오른쪽 편집 패널이 열립니다.
    편집 패널오른쪽선택한 항목의 모든 데이터 필드를 수정할 수 있습니다.
    상태 표시줄헤더 우측로드된 파일 수·로딩 상태가 표시됩니다.

    ▶ 검색

    목록 위의 검색창에 이름이나 내부 ID를 입력하면 목록이 실시간으로 좁혀집니다. 한국어 번역을 불러온 경우 한국어로도 검색할 수 있습니다.

    ✏️ 편집 방법

    ▶ 저장과 취소

    동작단축키버튼
    저장Ctrl+Shift+S (Mac: Cmd+Shift+S)편집 패널 우측 상단의 저장 버튼
    취소Esc편집 패널 우측 상단의 취소 버튼
    💡 취소를 누르면 마지막 저장 상태로 되돌아갑니다. 저장 버튼을 누르기 전까지 실제 파일에는 변경이 반영되지 않습니다.

    ▶ 항목 삭제

    편집 패널 오른쪽 상단의 🗑 삭제 버튼을 누르면 버튼이 빨간색으로 바뀌며 "한 번 더 클릭하면 삭제" 상태가 됩니다.
    실수 방지를 위해 3초 이내에 한 번 더 클릭해야 실제로 삭제됩니다. 3초가 지나면 자동으로 취소됩니다.

    ⚠️ 삭제한 항목은 복구할 수 없습니다. 저장 전에는 취소 버튼으로 되돌릴 수 있습니다.

    ▶ 새 항목 추가

    1. 목록 패널 위의 + 새 항목 버튼 클릭 (일부 탭에서만 표시됩니다)
    2. 내부 ID 입력 후 추가 (또는 Enter)
    3. 목록 맨 아래에 새 항목이 생성되고 편집 패널이 열립니다
    💡 내부 ID란 게임 내부에서 사용하는 식별자입니다. MY_NEW_MOVE, CUSTOM_POKEMON처럼 대문자 영문과 밑줄(_)만 사용하는 것이 안전합니다. 이미 같은 ID가 있으면 추가가 거부됩니다.

    ▶ 특수 필드 종류

    필드입력 방식예시
    Types (타입)드롭다운 2개 (제1·제2타입)FIRE / FLYING
    BaseStats (기본 능력치)HP·공격·방어·특공·특방·스피드 6칸 숫자45 / 49 / 49 …
    Moves (습득기)레벨 + 기술 이름 콤보박스 세트, + 버튼으로 행 추가Lv.1 — TACKLE
    Abilities (특성)콤보박스 + 버튼으로 행 추가 (최대 2개)OVERGROW
    GenderRatio (성별 비율)드롭다운 (♂ : ♀ 비율)87.5 : 12.5 / 불명
    Flags (기술 플래그)체크박스 목록 + 커스텀 입력란Contact, Sound …
    기술명 검색 콤보박스클릭하거나 이름을 입력하면 자동완성 목록 등장WATERFALL

    📂 탭별 설명

    🐾 포켓몬 (pokemon.txt 등)

    포켓몬의 타입·능력치·특성·기술·도감 설명 등 종족 데이터를 편집합니다.
    포켓몬 Gen9 탭은 Gen9 추가 팩 전용 데이터입니다. 폼 탭은 폼 변환 데이터입니다.
    Generation 필드(1~9)가 설정된 포켓몬은 목록에서 해당 세대 테마 색상으로 배경이 표시됩니다.

    ⚔️ 기술 (moves.txt 등)

    기술의 타입·분류·위력·명중·PP·효과·플래그 등을 편집합니다.
    Flags(플래그)는 체크박스로 표준 플래그를 선택할 수 있고, 목록에 없는 커스텀 플래그는 아래 커스텀 입력란에 쉼표로 구분해 직접 입력합니다.

    🗺️ 서식 분포 (encounters.txt)

    각 맵에서 어떤 포켓몬이 어떤 확률로 출현하는지 편집합니다.
    서식 타입(Land, Water, Cave…)별로 슬롯을 추가하고, 각 슬롯에 포켓몬·확률·레벨 범위를 지정합니다.

    👤 트레이너 (trainers.txt, trainer_types.txt)

    트레이너의 파티(포켓몬·레벨·기술·노력치·개체값 등)와 소지 아이템, 패배 대사를 편집합니다.
    같은 이름의 트레이너를 여러 버전(Version 필드)으로 구분해 시나리오 분기를 만들 수 있습니다.

    📁 커스텀 파일 자동 인식

    PBS 폴더에 _Custom.txt로 끝나는 파일을 만들어 두면, 폴더를 열 때 앱이 자동으로 해당 탭을 생성합니다.

    파일 이름 예시생성되는 탭카테고리
    PBS/moves_Custom.txt기술 커스텀기술
    PBS/pokemon_Custom.txt포켓몬 커스텀포켓몬
    PBS/encounters_Custom.txt서식 분포 커스텀서식 분포
    PBS/trainers_Custom.txt트레이너 커스텀트레이너
    • 기존 파일과 동일한 카테고리 드롭다운에 표시됩니다.
    • + 새 항목 추가와 저장(직접 쓰기 및 내보내기)이 모두 지원됩니다.
    • 파일 이름이 기존 PBS 파일과 대응되지 않으면(예: PBS/unknown_Custom.txt) 탭이 생성되지 않습니다.
    💡 앱 사용 중에 파일을 추가했다면 📂 폴더 선택으로 폴더를 다시 선택하면 새 탭이 나타납니다.

    🔧 기타 기능

    📋 변경 로그

    헤더의 📋 로그 버튼을 클릭하면 이 세션에서 수정한 모든 항목과 변경 내역을 확인할 수 있습니다.
    텍스트로 내보내기로 로그를 파일로 저장할 수 있습니다. 로그는 브라우저를 닫아도 다음 세션에 유지됩니다.

    🌐 한국어 번역 불러오기

    1. 🌐 번역 폴더 버튼 클릭
    2. 프로젝트의 Text_korean_core 또는 Text_korean_game 폴더를 선택
    3. 포켓몬·기술·특성·아이템 이름이 한국어로 표시되고, 한국어 검색도 가능해집니다

    💾 파일 내보내기

    헤더의 💾 파일 내보내기 버튼을 클릭하면 현재 탭의 전체 데이터를 파일로 다운로드합니다.
    Chrome/Edge에서 📂 폴더 선택으로 연 경우에는 저장 시 자동으로 파일에 직접 기록되므로, 이 버튼은 주로 다른 브라우저 사용 시 활용합니다.

    ❓ 자주 묻는 질문

    Q. 저장 버튼을 눌렀는데 파일이 바뀌지 않아요.

    A. Chrome 또는 Edge 브라우저에서 📂 폴더 선택으로 폴더를 연 경우에만 직접 저장이 됩니다. 처음 저장 시 브라우저가 파일 쓰기 권한을 요청하는 팝업을 띄울 수 있으니 허용을 클릭하세요.

    Q. 수정하고 저장했는데 게임에 반영이 안 돼요.

    A. RPGMaker XP / 게임을 완전히 종료하고 다시 실행해야 변경 사항이 반영됩니다.

    Q. 탭 이름 옆에 "(없음)"이라고 나와요.

    A. 해당 PBS 파일이 프로젝트 폴더에 없다는 뜻입니다. 플러그인 전용 파일(Gen9 팩 등)은 플러그인을 설치하지 않으면 없을 수 있습니다.

    Q. 기술의 플래그가 뭔가요?

    A. 플래그는 기술의 특성을 나타내는 태그입니다. 예를 들어 Contact가 있으면 접촉 기술, Sound가 있으면 소리 기술로 처리됩니다. 게임 엔진이 이 플래그를 읽어 특성(Iron Fist, 방음 등)과의 상호작용을 계산합니다.

    Q. GrowthRate(성장 속도)에 어떤 값을 선택해야 하나요?

    A. 드롭다운에서 선택합니다. 선택 가능한 값: Erratic(불규칙), Fast(빠름), Medium(중간), Parabolic(스타터 계열), Slow(전설·유사전설), Fluctuating(변동).

    Q. 실수로 항목을 삭제했어요.

    A. 삭제는 즉시 메모리에 반영되므로 취소할 수 없습니다. 아직 파일에 저장(Ctrl+Shift+S)하지 않았다면 앱을 새로고침하거나 폴더를 다시 선택해 원본 파일을 다시 불러오면 복구됩니다. 이미 저장했다면 변경 로그(📋)에서 이전 값을 확인해 수동으로 복구하거나, 백업 파일이 있다면 복원하세요.
